# ОБРАЗЕЦ. Положение об обработке и защите персональных данных (внутренний документ)

> Краткий образец для небольшой оптовой компании с сайтом. Публичная политика для клиентов — отдельный документ
> на сайте (`/privacy`); это — внутреннее положение для сотрудников. Юрист должен привести его к вашей
> ситуации.

## 1. Общие положения

1.1. Положение определяет порядок обработки и защиты персональных данных в ООО «________________» (далее —
Оператор) в соответствии с Федеральным законом № 152-ФЗ «О персональных данных».
1.2. Действие Положения распространяется на все данные клиентов (контактные лица юридических лиц, предприниматели),
посетителей сайта и работников Оператора.

## 2. Какие данные и где они находятся

| Где | Какие данные | Кто имеет доступ |
|---|---|---|
| Сайт и его база данных (сервер в РФ) | ФИО, телефон, почта, организация, ИНН, город, адрес доставки, заказы, обращения по качеству, журнал согласий | владелец (полный доступ); менеджеры (клиенты, заказы, рекламации) |
| Учётная система 1С (облако) | контрагенты, заказы, расчёты | бухгалтер, менеджеры по роли в 1С |
| Почта Оператора | переписка с клиентами | владелец, менеджеры |
| Бумажные документы | счета, накладные, листы сборки | склад, бухгалтерия |

## 3. Принципы

* обрабатываются только данные, нужные для целей (регистрация, заказы, расчёты, учёт, обращения);
* реклама — только по отдельному согласию клиента; отозвал — прекращаем немедленно;
* данные хранятся не дольше, чем нужно (сроки — в политике);
* доступ — по ролям и только тем, кому он нужен для работы.

## 4. Права и обязанности работников

4.1. Работник использует данные клиентов только для служебных задач и не передаёт их третьим лицам.
4.2. Работник не копирует данные клиентов на личные устройства, в личные мессенджеры и почту.
4.3. При увольнении доступ закрывается в тот же день (в админке: «Забрать роль менеджера», сброс пароля).
4.4. Каждый работник, допущенный к данным, подписывает обязательство о неразглашении (`employee_pd_obligation.md`).

## 5. Меры защиты

* вход на сайт по паролю (хранится хэшем), для администраторов — второй фактор (код из приложения);
* соединение с сайтом — HTTPS; сервер обновляется, настроен межсетевой экран;
* журнал действий сотрудников в админке; журнал обмена с 1С;
* резервное копирование (ежедневно) с хранением копии на другом сервере;
* ограничение частоты запросов и блокировка подбора пароля;
* ключи доступа 1С отключаются в админке, когда подрядчик закончил работу.

## 6. Обращения субъектов

6.1. Запросы (доступ, уточнение, удаление, отзыв согласия) принимаются через кабинет клиента, почту `{SHOP_EMAIL}`
и по телефону. Все обращения фиксируются.
6.2. Ответ — в срок, установленный законом (до 10 рабочих дней; продление — по закону с уведомлением).
6.3. Удаление: личные данные в системе сайта обезличиваются; данные, которые нельзя уничтожить из-за требований
закона (первичные учётные документы), хранятся до окончания срока и используются только для этой цели.

## 7. Инциденты (утечки)

7.1. Работник, заметивший утечку или подозрительный доступ, немедленно сообщает ответственному.
7.2. Действия — по `incident_plan.md`: уведомление Роскомнадзора в течение 24 часов, результаты расследования — в
течение 72 часов.
