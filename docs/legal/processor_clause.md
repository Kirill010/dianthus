# ОБРАЗЕЦ. Условие о поручении обработки персональных данных (для договоров с исполнителями)

> Образец для юриста. Вставляется в договоры с теми, кто получает или хранит персональные данные ваших клиентов:
> хостинг-провайдер, поставщик облачной 1С, почтовый сервис, транспортная компания/курьерская служба,
> подрядчик-программист (если имеет доступ к данным). Если у исполнителя есть собственная типовая оферта с
> такими условиями — достаточно убедиться, что они там есть.

**Поручение обработки персональных данных**

1. Заказчик (Оператор) поручает Исполнителю обработку персональных данных в объёме и в целях, необходимых для
   оказания услуг по Договору: ________________ (хранение данных сайта / ведение учёта в облачной 1С /
   рассылка уведомлений / доставка заказов).
2. Перечень данных: фамилия, имя, отчество, телефон, адрес электронной почты, адрес доставки, наименование
   организации, ИНН, сведения о заказах. Категории субъектов: представители клиентов Заказчика.
3. Действия: сбор, запись, хранение, использование, передача, удаление — в пределах услуг по Договору.
4. Исполнитель обязуется: обрабатывать данные только по поручению Заказчика; соблюдать конфиденциальность и
   принимать меры защиты, предусмотренные статьёй 19 Федерального закона № 152-ФЗ; **хранить данные граждан
   Российской Федерации на территории Российской Федерации**; не передавать данные третьим лицам без согласия
   Заказчика; сообщать Заказчику об утечках и инцидентах **без промедления** (чтобы Заказчик успел уведомить
   Роскомнадзор в течение 24 часов); по требованию Заказчика предоставлять информацию, подтверждающую
   выполнение условий; по окончании услуг удалить или вернуть данные.
5. Ответственность перед субъектами за действия Исполнителя несёт Заказчик, а перед Заказчиком — Исполнитель.
6. Срок действия поручения — срок действия Договора.
