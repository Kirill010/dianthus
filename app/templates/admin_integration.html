Что такое «ключ» и что с ним делать (за одну минуту)
  1. Создайте ключ ниже (кнопка «Создать ключ»). Ключ — это длинный пароль не для человека, а для программы: по нему сайт понимает, что к нему обращается именно ваша 1С.
  2. Отправьте программисту готовое сообщение (оно появится сразу после создания ключа). В нём адрес, ключ и ссылка на подробную памятку — больше ничего объяснять не нужно.
  3. Следите за плашкой выше. Когда программист закончит, она станет зелёной, а в журнале внизу появятся обращения 1С.
  4. Когда работа закончена или ключ попал не туда — нажмите «Отключить». 1С с этим ключом сразу перестанет входить; для работы можно создать новый.

Если из вашей 1С нельзя ходить в интернет (облако, запреты) — есть запасной путь через файлы, см. блок «Загрузка из файла» ниже.
